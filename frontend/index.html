Research Paper

Hybrid Student Performance Prediction Using Machine Learning and Learning Coefficients

Author: Pathi Partha Saradhi Reddy
Institution: Joy University, Dept. of Computer Science
Email: bcai23002@joyuniversity.edu.in
Under The guidance of: Prof.Mary Disilva Princy

Abstract

A hybrid ML framework combining academic records, behavioral patterns, and adaptive learning indicators. Five algorithms (LR, DT, RF, SVR, ANN) merged into a hybrid ensemble achieving 96.2% accuracy, supported by novel learning coefficients that track temporal student engagement.
